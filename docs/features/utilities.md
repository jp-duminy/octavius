# Utilities

## OctaviusConstants

The physical constants, scaling factors, and literature values used in the Octavius pipeline are stored in a lightweight dataclass called `OctaviusConstants`. This dataclass is exposed through the API for users to import. The constants are backed by `astropy` using the `iau2015` and `codata2022` modules. 

## Test Catalogues

For developers of codes which need to interface with Octavius catalogues, the `generate_test_catalogue()` method is provided. This generates a HDF5 catalogue with all the usual information and fields, but filled with placeholder values generated by creating a synthetic raw snapshot filled using `np.random.Generator`. This can be inspected with the `load_catalogue()` method or `h5py` to assess the file structure, dataset names, metadata, etc.

## Test Snapshots

The synthetic snapshot generator used to create test catalogues is also provided in the form of `generate_swift_snapshot()` and `generate_gizmo_snapshot()`. It can generate SWIFT and GIZMO snapshots containing all the fields necessary for the Octavius pipeline to run (which is a small subset of the total information contained in these snapshots). 

## Catalogue Repacking

Another utility function called `repack_catalogue()` is provided with the purpose of compressing Octavius catalogues with GZIP compression. This is a small utility which calls `h5repack` with the requested GZIP compression level using the default library `subprocess`, and replaces the catalogue with the repacked version. This can be used to further compress catalogues beyond the shuffle + GZIP-1 compression provided by the `compress_catalogue` flag in the configuration file.
